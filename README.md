# retail-data-pipeline
Retail Data Pipeline

An end-to-end data engineering project that ingests retail data,
cleans and transforms it using Python/PySpark, loads it into a
data warehouse, and creates analytical datasets for reporting.

Tech Stack
Python | SQL | PySpark | Databricks | Delta Lake | Power BI

Pipeline
Source → Ingestion → Transformation → Storage → Analytics → Dashboard

Key Features
- Incremental data loading
- Data-quality checks
- SCD Type 2
- Partitioning
- Analytical SQL
